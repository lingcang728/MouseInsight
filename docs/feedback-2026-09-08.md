## beta.5 本地 Windows 验收

后续截图暴露了 beta.4 的拖动越界、失焦残留位移及原生亮色滚动条问题，本节取代上方对应交互结论。

- 拖动改用逐帧跟手，依据卡片实际宽度完成退场；短拖回弹、达到距离或速度阈值后切卡。
- 拖动与退场时，真实下一张内容作为不可交互预览同步缩放、模糊到清晰；系统减少动态效果设置生效。
- 失焦、键盘快捷键、丢失指针捕获、取消、窗口尺寸变化及页面重绘均清理位移、预览和动画。松手后不会继续跟随鼠标。
- 工作台裁切动效范围；主内容禁止横向滚动，纵向改成随主题变化的细滚动条。
- 版本清单及锁文件统一为 `0.2.0-beta.5`，只构建 Windows。本地 EXE 与安装包供用户验收，未提交、推送、打 tag 或发布。
- WebView2 回归新增拖动中溢出与模糊检查、失焦/截图快捷键/丢失捕获中断、短拖复位和配置不变断言。截图中断由派发对应键盘/失焦事件验证，不宣称自动测试实际启动了 Windows 截图工具。

最终 beta.5 Release EXE 已完成完整 WebView2 回归，包含三张卡片双向循环与退场动画中断恢复，页面异常为零。IPC 返回版本 `0.2.0-beta.5`、监听 `ready`。验证产物保存在 `release/metadata/ui-beta5-final/`。本地运行 EXE 与测试 EXE 的哈希一致，原配置哈希保持不变；此前 beta.4 的最终隔离复验限制不适用于本次 beta.5。
